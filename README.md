## 📖 About the Project

**Yummy Eats** is a responsive restaurant discovery web application designed to help users explore and discover restaurants easily.  
The site features a clean, user-friendly interface with category-based filtering, search functionality, and visually appealing restaurant cards.

This project emphasizes **front-end development fundamentals** — layout, responsiveness, accessibility, and user experience — without relying on external frameworks.

---

## 🧩 Features

- 🍔 **Restaurant Search:** Browse restaurants with a structured and easy-to-navigate layout.  
- 🧭 **Category Filters:** Sort restaurants by food type for faster discovery.  
- 💬 **Interactive UI:** Includes hover effects and dynamic content presentation.  
- 📱 **Responsive Design:** Optimized for desktop, tablet, and mobile screens using CSS Grid and Flexbox.  
- ⚡ **Lightweight & Fast:** Pure HTML, CSS, and vanilla JavaScript implementation for performance and simplicity.
